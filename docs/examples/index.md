# Ejemplos

Índice de los sketches de `examples/`. Cada página muestra el archivo completo, leído del
repositorio al construir el sitio, junto con los componentes que usa, sus dependencias y
los pines que declara.

!!! warning "Estado de validación"
    - La CI (*Compile Examples*) compila todos los sketches para `esp32:esp32:esp32` y
      `esp32:esp32:esp32s3`. Esa compilación **no** se ejecutó al generar este sitio.
    - Ningún ejemplo se ha ejecutado en hardware para esta documentación: no hay salida
      observada, solo la que se deduce del código.
    - Los pines y periféricos son los del propio sketch; no constituyen un esquema eléctrico
      verificado.

Para empezar, usa [StatusIndicator](StatusIndicator.md): solo necesita un LED.
